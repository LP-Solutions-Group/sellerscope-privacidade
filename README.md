# Política de Privacidade — SellerScope ML

A política publicada em
<https://lp-solutions-group.github.io/sellerscope-privacidade/>,
que a ficha da Chrome Web Store aponta.

Este repositório é **público de propósito**: a Web Store exige que a política
esteja acessível sem login. Ele contém a política e nada mais — o código da
extensão vive em outro lugar, privado.

Para atualizar: edite `docs/privacidade.html` no repositório da extensão e
copie o resultado para o `index.html` daqui, para não existirem duas versões
divergindo.
